# 校园系统探索站 · 六年级第4课

完整课堂应用《输入输出与计算》。项目含学生端、班级大屏、本地数据库、六年级名单和可搬迁资源，不需要实时AI或外网素材。

## Netlify 云端课堂服务

云端学生入口：`https://6-4-shurushuchuyujisuan.netlify.app/`。已接入 Netlify Functions 与 Postgres 持久化数据库，正式名单和已有记录已经迁入；实际网址验收结果见 `docs/云端修复交付说明.md`。本地课堂启动方式继续保留。

云端教师双击 `打开云端教师大屏.command` 使用独立专用入口，免输入教师密码。入口文件保存在本机私有目录 `.private/教师专用入口.txt`，不要发给学生或提交到 GitHub；打开后地址会跳转到 `/teacher`，授权会话有效8小时。直接访问教师页面、答案和管理接口均需此授权。HTTPS页面可直接申请麦克风权限。

云端名单和学习记录保存在服务端数据库，`public/` 和公开仓库不包含真实名单或SQLite。为提供班级选名功能，学生接口按所选班级返回姓名；课堂选名仍是身份选择，不是密码认证。

`npm run prepare:cloud-data` 只读导出本地名单和已有记录，生成权限受限的 `.private/` 备份及数据迁移文件。身份ID、轮次、学习状态、事件ID和考核记录均保留；重复导入不会覆盖已有云端学习状态。私有迁移文件只用于正式数据迁移，不提交仓库，不作为静态文件发布。名单变更应单独核对后迁移，不通过重新建库或清空记录处理。

`npm run test:cloud` 使用虚构名单验证云端接口、权限、进度恢复、去重和数据迁移。真实云端测试预览与正式数据库分别验证，不能把本地测试通过当作线上已修复。

## 上课入口

双击 `启动课堂.command`；需要 Node.js 22.13 或更新版本。教师本机地址 `http://localhost:8794/teacher`，学生同一局域网访问终端显示的 `http://教师电脑IP:8794/`。

教师端已免密码。教师电脑可以打开 `http://localhost:8794/teacher`，也可以通过自己的局域网IP打开 `http://教师电脑IP:8794/teacher`；教师测试模式从大屏进入。服务端只接受教师电脑自身地址的管理请求，其他学生设备不能打开教师页面、教师数据、答案或开新轮次；学生端不显示教师入口。新版首次启动会移除旧版自动生成的教师密码文件，课堂学习记录不受影响。

登录页只列601—606班，已从本项目六年级名单导入314人。学生先选班级再选姓名，可搜索；名单外姓名可手动录入；与已有姓名相同会要求确认已有身份。选名是课堂身份选择，不是密码账户。

## 一节课怎样使用

主线：红灯反应 → 声控灯 → 汉字输入 → 自动门迁移。每关按“先想一想 → 做实验 → 搭流程图”三步进行。页面常驻当前操作指令，默认标出可操作的位置；对照实验的结果自动保存，流程图选完后再呈现新条件判断。汉字关输入一个词并点击“完成输入”即可保存结果。错误不扣积分，提示分三级。每关10积分，同一轮只记一次；知识考核成绩独立显示。

本轮根据“学生不知道点哪里”的课堂反馈减少了手动记录和同时出现的选项，原31分钟探究预估需重新校准。建议先做四关主线，再安排交流和考核；实验时间应让学生观察、比较并说明理由。每次20题考核另排12—15分钟，考前可返回继续学习，不阻塞主线；40题库覆盖五项目标，抽题的等值性尚未施测验证。

20题考核可以重复进行：每次完整提交后保留该次成绩，结果页把错题集中列在前面并自动展开，逐题显示自己的选择、正确答案和解析；答对的题目可按需展开。点击“再考一次 · 新抽20题”会从40题库重新抽题，前后两次可能有部分相同题目。刷新或返回考核页后，已提交的学生仍可查看最近一次结果。提交后另有选做奖励“2048 数字合并”：学生用方向键或按钮移动数字，旁侧同步显示输入方向、实际发生的处理和可见结果。奖励不设分数门槛，不改变考核成绩和通关积分。游戏来源、版本和MIT许可见 `public/vendor/2048/SOURCE.md`。

只有教师机或少量设备有麦克风：教师大屏“开启教师机麦克风”，学生先预测，再展开“选用现场麦克风 / 观察教师”，将声源选为“观察教师现场实测”；页面自动保存有效的安静与发声状态。请附近学生正常说话/轻拍手比较，不需要全班喊叫。小组轮换可实际采声，其余电脑使用明确标记的模拟声音。数据记录区分三种来源。

## 麦克风与仿真边界

- 需主动点击开启并在浏览器允许使用；校准时安静约1.5秒。不录制、不上传原始音频，不识别词句，仅计算相对响度；数值不是声学分贝。
- 教师电脑打开 `http://localhost:8794/teacher` 或自己的 `http://教师电脑IP:8794/teacher`，点击“开启教师机麦克风”。本机地址直接申请麦克风；HTTP局域网IP页面会打开一个 `localhost` 授权窗口，在新窗口允许麦克风后即可切回大屏测试，无需配置HTTPS。如果窗口被浏览器拦截，请允许本站弹窗后重试。
- 教师机在演示页、隔离测试页或学生实验页选择“本机麦克风 · 实测”时，同样会自动打开授权窗口并把结果带回原页面，自动保存声音对照。窗口地址跟随当前服务端口，8794或8795均可使用。
- 授权窗口须保持打开，可以切回当前页面。后台声音分析不依赖动画帧；点击停止、切换关卡或关闭窗口会释放设备。学生电脑用局域网HTTP页面选择“观察教师现场实测”看同步灯光，或使用模拟声音；每台学生机要独立采声时仍需可信HTTPS。
- 声音触发后灯保持5秒，再次有效声音延长保持；停止采声释放麦克风。环境光固定较暗，真实声控灯产品可能还包含光控等规则。
- 自动门以虚拟人物位置仿真，无摄像头；人停留检测区时保持开，离开后延时关。灯、门、轨迹、记录使用同一规则。
- 汉字关使用真实输入法与候选字选择，模拟输入保留模拟标记。不要以仿真结果宣称测得实际传感器或输入法算法。

## 教师大屏与隔离测试

显示名单人数、已进入、未进入、进行中、完成主线和四关完成比例；学生进度、积分、首次/最近考核、最近同步时间与具体证据。手动加入学生计入分母。每5秒刷新，失败会显示旧数据状态。

教师在本机大屏点击“进入教师测试模式”，即可用虚构身份自由进入四关，查看当前关的标准操作、预测示例、输入—计算—输出流程图答案和迁移判断；也可载入达标示例，亲自操作并检验。测试工具还可展开40题题库的正确答案和解析、填写并提交20题测试卷，以及不用先考核就直接试玩2048奖励。测试记录不写入真实学生进度、积分和考核统计。`/demo` 是无身份演示，也不写真实记录。教师测试入口 `/test` 和答案接口仅限教师电脑本机访问。

“开启本班新轮次”保留旧轮记录；重新计本轮进度和积分。旧轮待同步记录会显示冲突，不能自动覆盖新轮。学生可随时导出未完成JSON学习报告，教师可导出班级JSON。

## 保存、备份与迁移

课堂数据：`runtime/classroom.sqlite`。服务重启保留进度、首答、提交和考核，同一服务换设备登录恢复已同步记录。断网事件先放本机，以身份和轮次隔离，恢复后补传并去重；显示“未同步”时不可视为已保存到大屏。切换学生前尝试同步，未传记录留在原身份。新设备无法读取旧设备尚未上传的记录。

备份时先停止服务，再复制整个 `runtime/`。迁移到新教师电脑：复制整个应用目录和私有的 `roster.json`、备份数据，安装 Node22.13+ 后运行 `npm start`；学生访问新电脑启动时显示的地址，不写死IP。

名单与runtime不在public目录、不可通过学生网页整份下载，并已列入.gitignore。公开源码包使用 `roster.example.json`。真实名单和课堂记录不提交公开 GitHub；仓库地址与学生上课网址分别使用。云端部署状态见本文件前面的 Netlify 说明。

新版名单导入：安装Python openpyxl后运行 `python3 tools/import-roster.py /完整路径/六年级班级姓名名单.xlsx`。名称/班级/同名序号生成稳定ID；导入不会删除旧数据库记录。若更名或同班重名顺序变化，需要教师核对身份对应后迁移，避免错误合并。

## 真实情境图片与提示指引

四个学习场景配有 AI 生成的写实情境图，学生先观察可见信息，再回到可操作的3D／2D场景检验。图片的来源和观察边界见 `docs/情境图素材.md`。点击“给我一点提示”后，页面会标出下一步该操作的位置；完成该动作后指引停止。系统设置减少动态效果时保留静态轮廓提示。

## 班级图表与核对口径

教师大屏选择601—606班后，图表、学生明细与导出均使用该班当前学习轮次的数据。顶部状态图把全班分成未进入、进行中、完成主线三类；四关横条的分母为该班名单人数（含手动加入）。点击状态或关卡横条，可以在下方查看对应学生，点击“清除图表筛选”恢复全班明细。姓名搜索和“只看未完成”只影响明细列表，不改变全班图表。

“提交后的目标表现”分别显示首次、最近正式提交中符合本关量规的人数，二者都以本关已正式提交者为分母，未提交人数单列；这些数据不能单独当成稳定掌握。图表标明人数和分母，班级切换时清空旧班画面，数据加载失败时提示当前不是实时数据。

## 搭建工作过程流程图

四个必做场景均让学生在相连的“输入 → 计算 → 输出”节点中搭建工作过程图。点击节点，再从下方词卡中选择对应描述；三个节点会显示学生当前选择，可以随时点回去修订。提示按钮会指出待操作或待修订的节点，提交后的判定仍结合本关实际操作、结果与迁移解释。旧学习记录中的三环节选择会自动显示在新流程图中，不需要重新录入。

## 学生三步交互（2026-09-30）

每关只呈现当前任务。先选一个预测，页面自动进入实验；对照结果保存后，点击“实验已记好，搭流程图”。三个流程节点按顺序选择词卡，已填节点可点回去修改；最后直接点击新条件判断并检验。预测错了可以继续，解释错了会标出要修订的位置。初始情境图保留，其他步骤可点击“看情境图”回看。

路口关作为入门观察样例，只需点击“观察红灯”和“观察绿灯”，行人的反应会自动保存；预测、流程图和迁移判断仍由学生选择。声控灯默认显示“测试安静”和“发出明显声音”，现场选项折叠；人物远处/靠近的门状态在实际稳定后自动保存。灯的5秒保持与门的延时关闭仍然运行，不能在尚未熄灯或关门时伪造对照记录。旧草稿会根据已有证据恢复到合适步骤。
