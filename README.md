# 校园系统探索站 · 六年级第4课

完整课堂应用《输入输出与计算》。项目含学生端、班级大屏、本地数据库、六年级名单和可搬迁资源，不需要实时AI或外网素材。

## 上课入口

双击 `启动课堂.command`；需要 Node.js 22.13 或更新版本。教师本机地址 `http://localhost:8794/teacher`，学生同一局域网访问终端显示的 `http://教师电脑IP:8794/`。

教师密码首次启动自动生成，保存在 `runtime/teacher-password.txt`，之后保持不变。可以通过 `TEACHER_PASSWORD` 环境变量指定。教师大屏和测试入口均由服务端验证权限。

登录页只列601—606班，已从本项目六年级名单导入314人。学生先选班级再选姓名，可搜索；名单外姓名可手动录入；与已有姓名相同会要求确认已有身份。选名是课堂身份选择，不是密码账户。

## 一节课怎样使用

主线：红灯反应 → 声控灯 → 汉字输入 → 自动门迁移。先预测、操作对照、记录结果，再补工作过程示意图与新条件解释。错误不扣积分，提示分三级。每关10积分，同一轮只记一次；知识考核成绩独立显示。

40分钟预估：登录与情境4分钟；红灯3分钟；教师现场声控7分钟；学生独立仿真与解释8分钟；汉字7分钟；自动门6分钟；交流3分钟；缓冲2分钟。约31分钟探究，需要真实课堂校准。每次20题考核另排12—15分钟，考前可返回继续学习，不阻塞主线；40题库覆盖五项目标，抽题的等值性尚未施测验证。

只有教师机或少量设备有麦克风：教师大屏“开启教师机麦克风”，学生先预测，再将声源选为“观察教师现场实测”。请附近学生正常说话/轻拍手比较，不需要全班喊叫。小组轮换可实际采声，其余电脑使用明确标记的模拟声音。数据记录区分三种来源。

## 麦克风与仿真边界

- 需主动点击开启并在浏览器允许使用；校准时安静约1.5秒。不录制、不上传原始音频，不识别词句，仅计算相对响度；数值不是声学分贝。
- 教师本机的 localhost 可申请麦克风；远端学生普通局域网HTTP通常不能采声，有麦克风的远端设备需可信HTTPS。HTTP学生仍可观察教师共享结果和独立模拟，不要求关闭浏览器安全设置。
- 声音触发后灯保持5秒，再次有效声音延长保持；停止采声释放麦克风。环境光固定较暗，真实声控灯产品可能还包含光控等规则。
- 自动门以虚拟人物位置仿真，无摄像头；人停留检测区时保持开，离开后延时关。灯、门、轨迹、记录使用同一规则。
- 汉字关使用真实输入法与候选字选择，模拟输入保留模拟标记。不要以仿真结果宣称测得实际传感器或输入法算法。

## 教师大屏与隔离测试

显示名单人数、已进入、未进入、进行中、完成主线和四关完成比例；学生进度、积分、首次/最近考核、最近同步时间与具体证据。手动加入学生计入分母。每5秒刷新，失败会显示旧数据状态。

“隔离测试模式”可自由选关、载入关卡示例、查看20题参考答案、体验达标路径，不写入真实学生统计。`/demo` 是无身份演示，也不写真实记录。

“开启本班新轮次”保留旧轮记录；重新计本轮进度和积分。旧轮待同步记录会显示冲突，不能自动覆盖新轮。学生可随时导出未完成JSON学习报告，教师可导出班级JSON。

## 保存、备份与迁移

课堂数据：`runtime/classroom.sqlite`。服务重启保留进度、首答、提交和考核，同一服务换设备登录恢复已同步记录。断网事件先放本机，以身份和轮次隔离，恢复后补传并去重；显示“未同步”时不可视为已保存到大屏。切换学生前尝试同步，未传记录留在原身份。新设备无法读取旧设备尚未上传的记录。

备份时先停止服务，再复制整个 `runtime/`。迁移到新教师电脑：复制整个应用目录和私有的 `roster.json`、备份数据，安装 Node22.13+ 后运行 `npm start`；学生访问新电脑启动时显示的地址，不写死IP。

名单与runtime不在public目录、不可通过学生网页下载，并已列入.gitignore。公开源码包使用 `roster.example.json`。本次没有发布仓库或部署到互联网。

新版名单导入：安装Python openpyxl后运行 `python3 tools/import-roster.py /完整路径/六年级班级姓名名单.xlsx`。名称/班级/同名序号生成稳定ID；导入不会删除旧数据库记录。若更名或同班重名顺序变化，需要教师核对身份对应后迁移，避免错误合并。

## 检查

`npm test` 验证规则、服务权限、首答/最近、身份隔离、积分去重、轮次、考核以及麦克风处理边界。浏览器与硬件验证范围见 `docs/验收记录.md`。

## 真实情境图片与提示指引

四个学习场景配有 AI 生成的写实情境图，学生先观察可见信息，再回到可操作的3D／2D场景检验。图片的来源和观察边界见 `docs/情境图素材.md`。点击“给我一点提示”后，页面会标出下一步该操作的位置；完成该动作后指引停止。系统设置减少动态效果时保留静态轮廓提示。

### 班级图表与核对口径

教师大屏选择601—606班后，图表、学生明细与导出均使用该班当前学习轮次的数据。顶部状态图把全班分成未进入、进行中、完成主线三类；四关横条的分母为该班名单人数（含手动加入）。点击状态或关卡横条，可以在下方查看对应学生，点击“清除图表筛选”恢复全班明细。姓名搜索和“只看未完成”只影响明细列表，不改变全班图表。

“提交后的目标表现”分别显示首次、最近正式提交中符合本关量规的人数，二者都以本关已正式提交者为分母，未提交人数单列；这些数据不能单独当成稳定掌握。图表标明人数和分母，班级切换时清空旧班画面，数据加载失败时提示当前不是实时数据。
