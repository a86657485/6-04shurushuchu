# 校园系统探索站 Implementation Plan

> For agentic workers: 执行本课已确认的优化方案，逐项检查。用户已授权开始完整制作，项目放在第四课文件夹。

**Goal:** 完成六年级第4课真实声控、场景探究、20题考核和班级大屏。

**Architecture:** 原生网页与本地Node课堂服务，SQLite持久化。声音/门的模型与画面使用同一状态。所有课堂事件带身份、学习轮次及唯一编号，服务端验证目标证据并去重奖励。

**Tech Stack:** Node 22内置SQLite、Three.js固定视角、Web Audio、glTF小递模型；不调用实时模型。

## 课堂边界

40分钟主线约31分钟探究；20题考核另排12—15分钟。无麦克风学生可走独立仿真路径，数据明确标注；只有教师机/少量设备实测。教师本机localhost采声，学生HTTP可观察教师共享事件；异地有麦克风设备采声需可信HTTPS。响度不标真实分贝，5秒保持属教学仿真设置。
