# 第4课云端课堂使用说明

2026-10-10，学生名单和后端已在原网址恢复。

学生入口：<https://6-4-shurushuchuyujisuan.netlify.app/>。先选班级，再选姓名进入；页面通过同一网址的服务端接口保存学习进度、通关积分和考核。

教师在本项目双击 `打开云端教师大屏.command`，即可进入独立大屏，不需要输入教师密码。也可以打开 `.private/教师专用入口.txt`，将文件中的完整网址复制到浏览器。授权会话有效8小时，到期后再次使用专用入口。该入口只交给教师，不发到学生群；学生页面不显示教师入口。

## 保存与备份

本地原始 `roster.json` 和 `runtime/classroom.sqlite` 保持保留。`.private/` 中保存正式迁移前的逻辑快照、私有SQL、校验文件及正式网址核验报告。请保留整个私有目录，勿提交GitHub或放入网页公开目录。

云端数据不依赖教师电脑持续开机；浏览器断网时保留本机待同步记录，恢复后补传。只有显示已同步的记录才能在其他设备恢复。更新名单应保留稳定ID，不清空数据库或重置现有学习状态。
